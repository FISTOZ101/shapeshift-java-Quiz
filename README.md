 Quizzy — Dynamic Picture Quiz Experience

Quizzy is an interactive Java-powered picture quiz that transforms visuals as you answer questions — each correct or selected answer triggers a change in the imagery, giving the quiz a dynamic, shape-shifting feel that keeps users engaged. Players navigate through a series of questions while watching the related images morph and evolve based on their responses, creating a fun, visual way to test knowledge and explore how each choice affects the outcome. Simple, responsive, and play-focused, this project blends quiz logic with visual transformation to make learning playful and immersive
